# Machine learning in heart and lung transplantation: systematic review and meta-analysis (analysis code and data)

Code and data to reproduce the tables, figures, and statistics of:

> Machine learning and the donor–recipient dual-risk problem in heart and lung transplantation: a systematic review and meta-analysis. PROSPERO CRD420251174511.

All analyses start from the locked extraction database of the 78 included studies. Running the pipeline reproduces the values reported in the manuscript; `check_results.py` confirms this.

## Contents

| Folder / file | Content |
|---|---|

| `data/included_studies.csv` | The 78 included studies with DOI |
| `data/feature_counts.csv` | Number of predictors per model (predictor-count analyses and Figure S3) |

| `search/search_strings.md` | Full search strings for all sources and searches |
| `search/pubmed_search_test.py` | Re-runs the PubMed search and checks that it retrieves the included studies |
| `analysis/scripts/` | Analysis scripts (Python and R) |
| `run_pipeline.py` | Runs all analysis steps in order |
| `LICENSE` | Terms of use (all rights reserved) |
| `pyproject.toml`, `install_r_packages.R` | Python (uv) and R dependencies, pinned to the versions used |
| `check_results.py`, `expected_results.json` | Compares the outputs with the values in the manuscript |

Figure 1 (PRISMA flow diagram) was drawn by hand and is not generated by the code.

## Run

Requirements: [uv](https://docs.astral.sh/uv/) for Python (3.13, versions pinned in `pyproject.toml`) and R 4.5 with `Rscript` on the PATH.

```bash
Rscript install_r_packages.R          # once: metafor, readxl, dplyr, forestploter, gridExtra
uv run python run_pipeline.py --check
```

A full run takes about one minute.

`--check` ends with `ALL MATCH` when every checked number equals the manuscript: pooled AUROC, 95% CI, prediction intervals, and I² for the three pooled subgroups; the registry sensitivity analysis; the paired machine-learning versus linear comparison; the cohort-size and input-type analyses; and the Table 1 counts.

## Reproducibility notes

- Statistics (csv and json) are identical to those behind the manuscript. Figures have the same content; PDF and PNG files embed creation dates, and the R PNG device can shift the layout by a pixel, so files are not byte-identical.
- The R outputs store values to four decimals. A value printed with three decimals in the manuscript (for example 0·966) can therefore differ from rounding the stored value (0·9665); `check_results.py` allows for this.
- The PubMed search can be repeated with `python search/pubmed_search_test.py`. Counts drift slightly over time because PubMed indexing changes. The other databases (Embase, Web of Science, Scopus, Inspec, CENTRAL) and the trial registries require their own interfaces; the strings are in `search/search_strings.md`.
