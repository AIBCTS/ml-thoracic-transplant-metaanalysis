# PICOS framework

**Review question:** What is the role of artificial intelligence (machine learning) in thoracic transplantation — including candidate selection, donor evaluation, and post-transplant outcomes?

---

## Population

| | Criteria |
|---|---|
| **Include** | Adults |
| | Candidates listed for thoracic transplantation |
| | Recipients transplanted with a heart, lung, or heart-lung |
| | Heart and/or lung donors |
| **Exclude** | Articles focused on other treatments such as LVAD as destination therapy |
| | Animal studies |
| | Paediatric populations |

---

## Intervention / Exposure

| | Criteria |
|---|---|
| **Include** | An AI component defined as a non-linear computational model, including but not limited to: machine learning, decision trees, neural networks, random forests, gradient boosting, deep learning, and similar approaches |
| **Exclude** | Studies evaluating linear risk scores only (e.g. logistic regression, Cox regression without ML components) |
| | Studies where ML is used solely as a secondary analysis component — for example, where omics data are used to predict rejection and ML is used only to analyse the omics results, not as the primary analytical component |

---

## Comparator / Context

| | Criteria |
|---|---|
| **Include** | Current clinical practice (gold standard) |
| **Exclude** | — |

---

## Outcomes

| | Criteria |
|---|---|
| **Include** | Survival post-transplant |
| | Waitlist mortality |
| | Complications post-transplant |
| | Quality of life (QoL) post-transplant |
| | Health economics / cost-effectiveness |
| **Exclude** | — |

---

## Study characteristics

| | Criteria |
|---|---|
| **Include** | Published January 1 2018 or later |
| | Randomised controlled trials (RCT) |
| | Registry studies |
| | Observational studies |
| **Exclude** | Pre-publication / not yet peer-reviewed |
| | Non-English language journals |
| | Abstracts and conference proceedings |
| | Conference papers |
| | Case reports |
| | Narrative reviews and systematic reviews |
| | Letters to the editor |
| | Editorials |
| **Uncertain / maybe** | Meta-analyses (classify as maybe at screening) |

---

## Notes on borderline cases

- **ML as primary vs secondary component:** The key criterion is whether the ML model is the primary analytical tool being evaluated. If ML is used only to process the output of another method (e.g. proteomics, genomics), the study is excluded.
- **Linear models:** Logistic regression and Cox regression alone do not qualify. Studies comparing a ML model against a logistic regression baseline are included if the ML model is the focus.
- **Paediatric:** Exclude if the study population is entirely paediatric. Include if adults and children are combined and adult data can be extracted separately; flag for sensitivity analysis.
